Presentación del Proyecto

Objetivo General

El proyecto "Recuperación del Laboratorio" (asociado a la gestión de Proyecto Promoción) tiene como objetivo la rehabilitación, acondicionamiento e implementación de la infraestructura técnica y eléctrica del laboratorio para optimizar su uso en actividades educativas y prácticas.

Problema que Resuelve

Resuelve la falta de un espacio técnico adecuado, seguro e infraestructura eléctrica/informática optimizada para la realización de prácticas de la especialidad.

A quién Beneficia

Beneficia a toda la comunidad estudiantil y docente de la especialidad BATIN, garantizando un entorno apto para el aprendizaje práctico.

Evolución del Proceso (3 Años)

1° BATIN (Estudiantes)

Fase Inicial: Diagnóstico de infraestructura, relevamiento de necesidades técnicas/eléctricas y mantenimiento preventivo inicial.

2° BATIN (Estudiantes)

Fase de Implementación: Adecuación e instalación de cableado, tableros y acondicionamiento técnico del equipamiento.

3° BATIN (Estudiantes)

Fase de Gestión y Cierre: Implementación del sistema de software de gestión, pruebas, documentación técnica y entrega del laboratorio funcional.

Manual de Usuario

1. Introducción / ¿Para qué sirve el sistema?

Este sistema permite gestionar el acceso, el inventario técnico y las reservas de turnos de uso en el laboratorio recuperado.

2. Requisitos del Sistema

  • SO: Windows 10/11 o Linux.
  • RAM: 2 GB mínimo.
  • Entorno: Java JRE 8 o superior / Entorno PORTABLE.

3. Instalación / Cómo abrirlo

Ejecutar el archivo ejecutable o la carpeta contenedor desde la unidad portable sin necesidad de instalación previa.

5. Preguntas Frecuentes / Solución de Problemas

Q: ¿El sistema no arranca?
A: Verifique que la carpeta `BATIN_PORTABLE` mantenga la estructura de archivos original.

Manual de Programación

1. Arquitectura General

Interfaz de Usuario (GUI) ──> Conector JDBC ──> Base de Datos Relacional

2. Descripción de Clases Principales

  • Conexion.java: Gestiona la conexión mediante JDBC.
  • LaboratorioController.java: Controla las reglas de negocio y actualización de insumos/equipos.
  • Usuario.java: Modela los datos de los estudiantes y encargados.

3. Compilación y Ejecución (BATIN_PORTABLE)

1. Abra el directorio BATIN_PORTABLE.
2. Ejecute el script 'run.bat' o abra la consola y ejecute:
   java -jar SistemaLaboratorio.jar

4. Decisiones de Diseño y Librerías

Se optó por una arquitectura MVC (Modelo-Vista-Controlador) e implementación JDBC para mantener ligereza y portabilidad dentro del aula sin necesidad de internet.
